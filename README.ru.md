# MDPad 1.1.0

<a href="README.md">English</a> · **Русский**

Лёгкий блокнот для Windows 10/11 с нативной поддержкой Markdown. Открывает `.md`, `.markdown` и `.txt`.

## Возможности

- Редактор на CodeMirror 6 с подсветкой Markdown, поиском и заменой, переходом к строке
- Превью CommonMark + GFM: таблицы, чекбоксы, зачёркивание, автоссылки; широкие таблицы прокручиваются внутри превью, текст чекбоксов нормально переносится
- Правка прямо в превью: двойной клик по блоку открывает его Markdown на месте, двойной клик ниже текста добавляет новый блок; Ctrl+Enter или клик мимо — готово, Esc — отмена. Чекбоксы задач кликабельны
- Режимы: разметка / рендер (кнопка в шапке), сплит с перетаскиваемым разделителем (Ctrl+Shift+V)
- Синхронизация позиции по строкам исходника: двусторонняя прокрутка в сплите, то же место документа при переключении режимов; каждая вкладка помнит позицию
- Вкладки, Ctrl+Tab для переключения, закрытие последней вкладки закрывает приложение, подтверждение при закрытии несохранённых
- Кодировки: UTF-8, UTF-8 BOM, UTF-16, Windows-1251. Перевод строк CRLF/LF сохраняется
- Атомарная запись файлов (через временный файл)
- Язык интерфейса: русский или английский по языку системы; для любого другого языка — английский
- Тёмная тема, без телеметрии и сети

## Хоткеи

| Действие | Клавиши |
|---|---|
| Новый / Открыть / Сохранить / Сохранить как | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| Закрыть вкладку | Ctrl+W |
| Следующая / предыдущая вкладка | Ctrl+Tab / Ctrl+Shift+Tab |
| Найти / заменить / перейти к строке | Ctrl+F / Ctrl+H / Ctrl+G |
| Жирный / курсив (Markdown) | Ctrl+B / Ctrl+I |
| Сплит-режим вкл./выкл. | Ctrl+Shift+V |
| Переключить разметка / рендер | кнопка в шапке |
| Масштаб шрифта | Ctrl+колесо, Ctrl+= / Ctrl+-, Ctrl+0 |
| Настройки | Ctrl+, |

## Разработка

Требования: Node.js 20.19+ (или 22.12+), Rust (stable).

```bash
npm install
npx tauri dev        # запуск приложения (нужен WebView2 на Windows)
npm test             # тесты фронтенда (vitest)
cd src-tauri && cargo test
```

## Сборка установщика

```bash
npx tauri build
```

Установщик (NSIS) появится в `src-tauri/target/release/bundle/nsis/`, portable-версия — `src-tauri/target/release/mdpad.exe`.
[GitHub Actions](.github/workflows/release.yml) проверяет PR в `main`, запускает тесты, собирает обе версии и прикладывает контрольные суммы. При пуше тега `v1.1.0` публикуется релиз с установщиком `MDPad_1.1.0_x64-setup.exe`, портативной сборкой `MDPad_1.1.0_x64-portable.exe` и `SHA256SUMS.txt`. Ручной запуск workflow даёт артефакты, но не публикует релиз.

После принятия PR нужно обновить `main` и создать тег **именно на принятом коммите**:

```bash
git switch main
git pull --ff-only
npm run check:release -- v1.1.0
git tag -a v1.1.0 -m "MDPad v1.1.0"
git push origin v1.1.0
```

Текст релиза лежит в [`RELEASE_NOTES.md`](RELEASE_NOTES.md).

## Ассоциация с .md

Установщик регистрирует MDPad как редактор `.md` и `.markdown`. Windows 10/11 не позволяет программе назначить себя по умолчанию без участия пользователя:
выберите файл `.md` → «Открыть с помощью» → MDPad → «Всегда использовать это приложение».
